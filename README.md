# نراس | Neras — أندرويد + آيفون + ويب

تطبيق **منصة نراس للتثقيف النفسي الأسري** لأطفال التوحد وأسرهم.
مجلد واحد فيه ٣ نسخ من نفس التطبيق:

| المجلد | وش هو | يطلع منه |
|---|---|---|
| `web/` | التطبيق الأساسي (كل الألعاب والنصائح) | رابط يتثبّت على **آيفون وأندرويد** من المتصفح |
| `android/` | تطبيق أندرويد | ملف **Neras.apk** |
| `ios/` | تطبيق آيفون | ملف **Neras-unsigned.ipa** |

> أي تعديل على المحتوى يكون في `web/index.html` فقط، والنسختين الثانية تاخذه تلقائياً وقت البناء.

---

## الخطوة الأولى: ارفع المجلد على GitHub
1. أنشئ مستودع جديد في GitHub (مثلاً `neras-app`).
2. ارفع **كل** محتويات هذا المجلد، ومنها المجلد المخفي `.github`.
3. افتح تبويب **Actions**. بتشتغل ٣ عمليات بناء لحالها (حوالي ٥–١٠ دقائق).

## أندرويد: ملف APK
1. في **Actions** افتح «Android APK» ← آخر تشغيل.
2. نزّل **Neras-Android-APK** من أسفل الصفحة وفك الضغط.
3. انقل `Neras.apk` للجوال وثبّته (اسمح بالتثبيت من مصادر غير معروفة).

## آيفون: ٣ طرق

### ١) الأسهل والمجاني: تثبيت من الرابط (يشتغل اليوم)
1. في المستودع: **Settings ← Pages ← Source: GitHub Actions**.
2. بعد ما تخلص عملية «Web app» يطلع لك رابط مثل `https://اسمك.github.io/neras-app/`.
3. في الآيفون افتح الرابط في **Safari** ← زر المشاركة ⬆️ ← **إضافة إلى الشاشة الرئيسية**.
4. يطلع أيقونة «نراس» ويفتح كتطبيق كامل بدون شريط المتصفح، ويشتغل بدون إنترنت بعد أول فتح.

> نفس الرابط يشتغل على أندرويد من Chrome: القائمة ⋮ ← **تثبيت التطبيق**.

### ٢) ملف IPA للتجربة على جوالك
1. في **Actions** افتح «iPhone IPA» ← نزّل **Neras-iPhone-IPA**.
2. الملف **غير موقّع**، وآبل ما تسمح بتثبيته مباشرة. تحتاج برنامج توقيع مثل **Sideloadly** أو **AltStore** على الكمبيوتر مع حساب Apple ID.
3. بالحساب المجاني ينتهي التطبيق بعد ٧ أيام وتعيد توقيعه.

### ٣) الرسمي: App Store أو TestFlight
- تحتاج **حساب Apple Developer** (٩٩ دولار في السنة) وجهاز **Mac** فيه Xcode.
- على الماك: `brew install xcodegen` ثم داخل `ios/` نفّذ `xcodegen generate` وافتح `Neras.xcodeproj`.
- اختر حسابك في Signing، ثم **Product ← Archive** وارفعه لـ TestFlight أو App Store.

## قفل الجوال على التطبيق (مهم للطفل)
- **آيفون:** الإعدادات ← تسهيلات الاستخدام ← **الوصول الموجّه (Guided Access)**.
- **أندرويد:** الإعدادات ← الأمان ← **تثبيت التطبيق (App pinning)**.
